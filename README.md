# Avenzo Studio

Responsive static site for **Avenzo Studio**, focused on France / Europe ↔ China marketing and business services.

## Pages

- Accueil
- Services
- Le studio
- Contact

## Features

- Animated Europe → China air / sea route graphic
- Four interactive service categories
- Horizontal capability rail
- Detailed service workbench with scopes, deliverables and skills
- Mobile bottom navigation
- Mailto contact flow
- Reduced-motion support
- Netlify-ready static deployment

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
